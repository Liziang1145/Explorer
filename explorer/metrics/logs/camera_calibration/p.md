## 相机—车体 外参标定记录（平面法）

日期：2026-11-01　对象：AIPC 上的 Orbbec Gemini 335（`aipc-native-camera.service`，127.0.0.1:8098）
标定脚本：[calib_plane.py](calib_plane.py)　测量脚本：[measure_plane.py](measure_plane.py)　结果：[T_body_from_cam.json](T_body_from_cam.json)

### 1. 目的与坐标系

| 坐标系 | 定义 |
|---|---|
| `camera_color_optical_frame` | X 右 / Y 下 / Z 沿光轴（REP-103） |
| `body` | **X 右 / Y 前 / Z 上，原点 = 底盘上顶面中心** |
| 放置平面 | Z = **+70 mm**（比底盘上顶面高 7 cm） |

标定产物是一组 4×4 变换 `T_body_from_cam`（平移单位：米），把彩色相机像素反投影出的 3D 点直接映射到车体系。

### 2. 方法

**不用手眼标定的 AX=XB**，而是利用"标定板平放在已知水平面上"这一个强约束，把 6 自由度问题降成一次 PnP：

1. 棋盘（9×6 内角点、方格 35 mm）平放在 Z = +70 mm 平面上；
2. 量出板子**近边中点**在车体系的位置 →（X 0, Y 600, Z 70）；
3. 由此推出近边两端 P1（−140, 600）、P2（+140, 600）的坐标；
4. 用 `cv2.findChessboardCornersSB` 求 54 个角点像素，亚像素精度；
5. 把这 54 个角点在车体系下的 3D 坐标（棋盘格坐标 + 平面约束 + 两点定平面内旋转）与像素做 `solvePnP`，即得 `T_body_from_cam`。

**关键处理**：

- **平面 PnP 二重解**：平面目标存在镜像解（相机被放到平面另一侧）。用物理约束筛除——要求相机在平面**之上**且**光轴朝下**。用 `solvePnPGeneric(SOLVEPNP_IPPE)` 取两个候选，逐一检验。
- **棋盘手性歧义**：检测器给出的角点排序会随板子朝向翻转（实测两次运行翻转了 180°），因此 `j` 方向取两种手性各解一次，按残差与物理可行性择优。
- **参考角点按画面方位选取**（"最左/最右"），不按数组下标——下标会翻转，方位不会。

### 4. 精度与验证

#### 4.1 标定残差

| 指标 | 值 |
|---|---|
| 重投影 RMS | **0.309 px** |
| 最大角点误差 | 0.77 px |
| 量测间距一致性 | 280.0 mm（实测） vs 280.0 mm（棋盘标称） → **0.0 mm** |

0.309 px 在 0.6 m 处折合约 **0.27 mm** 的角点位置误差。

#### 4.2 独立传感器交叉验证

用**深度图**（独立于彩色 PnP 的另一条通路）反投影棋盘区域 79,197 个点并映射到车体系：

| 量 | 值 |
|---|---|
| 桌面点 Z 中位数 | **69.8 mm** |
| 标定平面标称值 | 70.0 mm |
| **偏差** | **−0.2 mm** |

彩色 PnP 与深度反投影两条独立链路互相印证，说明：相机内参、`depth→color` 出厂外参、棋盘位姿、平面高度四者自洽。

### 5. 已知偏差与边界

1. **地面高度口径差 43 mm**：由本标定链路反推，地面在 Z = **−397 mm**（相机离地 947 mm）；而机械参数台账实测"底盘上顶面距地面 440 mm"。两者差 43 mm，尚未对齐。不影响相对定位，但若要用 Z 做绝对抓取高度需先统一。
2. **只对落在平面上的物体成立**：本方法的 X/Y 来自"像素射线 ∩ 平面"，物体必须实际位于该平面上。离平面越远，投影到平面上的位置偏移越大（例如地面上的椅子会被投到更远处）。
3. **物体高度另算**：Z 由该像素处的深度单独给出，不参与平面定位。
4. **未做时间同步**：彩色与深度取帧时间差实测 0.1 ms（同一 frameset），静态场景无影响；运动场景未验证。

### 6. 复现步骤

```bash
## 1) 棋盘平放在 Z=+70 mm 平面上，量出近边中点的车体系 (X, Y)
## 2) 确认检测（会打印 P1/P2 像素与标注图）
python calib_plane.py list
## 3) 解算（示例：近边中点在 (0, 600)）
python calib_plane.py solve --p1-x -140 --p1-y 600 --p2-x 140 --p2-y 600 --plane-z 70
## 4) 每帧输出平面上物体的车体系坐标
python measure_plane.py --conf 0.35
```

### 7. 用途

输出格式（`measure_plane.py`）：

```json
[{"name": "cup", "conf": 0.94, "X_mm": -198.4, "Y_mm": 803.1,
  "Z_mm": 61.2, "above_plane_mm": -8.8, "footprint_px": 1475}]
```

`X/Y` 来自射线与平面求交（不受深度噪声与物体厚度影响），`Z` 来自深度。可直接作为"机械臂先移到附近、再由 VR 精调"的目标点。
