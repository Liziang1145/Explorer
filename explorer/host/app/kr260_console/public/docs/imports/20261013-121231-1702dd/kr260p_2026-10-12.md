### 3.2 网络问题排查（耗时最多的环节）

**现象**：`eth1` UP 且有 `LOWER_UP`（物理链路正常），但拿不到 IP。

排查过程：

```bash
ip link show eth1                 # 有 LOWER_UP → 物理层 OK
sudo dhclient -v eth1             # command not found（24.04 无此工具）
sudo netplan apply                # 无效
sudo systemctl restart systemd-networkd   # 服务未运行 → 网络归 NetworkManager 管
nmcli device status               # eth1: connecting (getting IP configuration)
sudo nmcli device connect eth1    # 报错：no available address, timeout
```

**根因**：网线另一端直插电脑，没有对端 DHCP 服务器。

**解决**：Windows 开启 **ICS（Internet 连接共享）**：
`Win+R` → `ncpa.cpl` → WLAN 属性 → 共享 → 允许共享到"以太网"口
→ Windows 自动在该口启用 DHCP（网段 192.168.137.x，主机 192.168.137.1）
→ KR260 自动获得 `192.168.137.224`，且可上网。

### 3.5 ARM64 原生编译

### 3.6 USB-CAN 接入与固定命名

适配器：candleLight USB to CAN（bytewerk），VID:PID `1d50:606f`，
与原 AI PC 工程同款 gs_usb 固件，内核自动识别出 `can0`。

- 序列号 `003900435746570F20383839` → 登记为**右臂**适配器
- udev 规则 `/etc/udev/rules.d/99-usb-can.rules` 将其固定命名为 `can2`：

```udev
ACTION=="add", SUBSYSTEM=="net", ATTRS{serial}=="003900435746570F20383839", NAME="can2"
```

- 启用：`sudo ip link set can2 type can bitrate 1000000 && sudo ip link set can2 up`
- 状态确认：`state UP`、`bitrate 1000000`、`ERROR-ACTIVE`（无错误）

### 3.7 右臂真机通信验证

接线：适配器 CAN_H/CAN_L/GND → 右臂 CAN 口，手臂独立供电。

`candump can2` 收到完整反馈帧流：

| 帧 ID | 内容 | 本次数据解读 |
|---|---|---|
| 0x251~0x256 | 各关节高速反馈（速度/电流/位置） | 见下方关节角表 |
| 0x261~0x266 | 低速反馈（电压/温度/状态） | 电压约 23V，温度 33~35°C，无告警 |
| 0x2A1 | 整机状态 | 全零（正常） |
| 0x2A2~0x2A8 | 末端位姿等扩展反馈 | 持续更新 |

当前关节角（位置字段 = 0.001° 大端整数）：

| 关节 | 帧 | 原始值 | 角度 |
|---|---|---|---|
| 1 | 0x251 | `00 00 00 4A` | 0.074° |
| 2 | 0x252 | `FF FF FF EE` | −0.018° |
| 3 | 0x253 | `FF FF FF FB` | −0.005° |
| 4 | 0x254 | `FF FF FB 44` | −1.212° |
| 5 | 0x255 | `00 00 05 53` | 1.363° |
| 6 | 0x256 | `00 00 00 15` | 0.021° |

→ 手臂处于零位附近，全零指令安全。

### 3.8 首次运动测试 ✅

```bash
cd ~/piper_dual_arm_teleop/build
./tool enable right                      # 使能（电机励磁）
./tool set right all 0 0 0 0 0 0         # 保持零位（几乎不动）
./tool set right all 0 0 0 0 0 0.1       # 第 6 关节转 0.1 rad（≈5.7°）
./tool set right all 0 0 0 0 0 0         # 转回
./tool disable right                     # 失能
```

**结果：机械臂按指令平滑运动并回到原位。** 🎉
KR260 对真实机械臂的控制链路验证通过。
