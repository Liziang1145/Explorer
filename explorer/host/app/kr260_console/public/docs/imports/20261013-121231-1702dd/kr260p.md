# KR260 右臂操作手册

> 用途：通过 KR260 + USB-CAN 适配器对右侧 Piper 机械臂进行使能、运动、监听与失能操作。
> 硬件：KR260（Ubuntu 24.04）、candleLight USB-CAN 适配器（序列号 003900435746570F20383839）、AgileX Piper 右臂。
> 程序位置：`~/piper_dual_arm_teleop/build/tool`

---

## 1. 开机准备（每次上电后执行）

```bash
# ① 插上 USB-CAN 适配器（udev 规则会自动命名为 can2）
# ② 确认识别
ip -br link        # 应看到 can2

# ③ 配置波特率并启用（机械臂为 1 Mbps）
sudo ip link set can2 type can bitrate 1000000
sudo ip link set can2 up

# ④ 确认状态（应显示 state UP、bitrate 1000000）
ip -details link show can2
```

> 如果第②步看到的是 `can0` 而不是 `can2`，说明 udev 规则未生效，
> 检查 `/etc/udev/rules.d/99-usb-can.rules` 是否存在，重插适配器。

## 2. 接线检查清单

- [ ] CAN_H、CAN_L、GND 三线连接牢固，无反接
- [ ] 机械臂独立电源已供电（反馈电压约 23V 为正常）
- [ ] 总线终端电阻正常（两端各 120Ω）
- [ ] 臂周运动空间清空
- [ ] 急停/断电措施在手边

## 3. 监听总线（验证通信）

```bash
candump can2        # Ctrl+C 停止
```

机械臂上电后应看到周期性反馈帧：

| 帧 ID | 含义 |
|---|---|
| 0x251~0x256 | 关节 1~6 高速反馈（速度/电流/位置，位置为 0.001° 大端整数） |
| 0x261~0x266 | 关节 1~6 低速反馈（电压/温度/状态字） |
| 0x2A1 | 整机状态 |
| 0x2A2~0x2A8 | 末端位姿等扩展反馈 |

参考零位数据（2026-10-12 实测）：

| 关节 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 角度 | 0.074° | −0.018° | −0.005° | −1.212° | 1.363° | 0.021° |

## 4. 使能与失能

```bash
cd ~/piper_dual_arm_teleop/build

./tool enable right      # 使能右臂（电机励磁，手臂"锁住"）
./tool disable right     # 失能右臂（测试结束后务必执行）
```

## 5. 关节位置运动

命令格式（角度单位为**弧度**，正反转方向相反）：

```bash
./tool set right all <关节1> <关节2> <关节3> <关节4> <关节5> <关节6>
```

常用指令：

```bash
# 回零位
./tool set right all 0 0 0 0 0 0

# 单关节小幅测试（±0.1 rad ≈ ±5.7°）
./tool set right all 0.1 0 0 0 0 0      # 关节1（底座旋转）
./tool set right all 0 0.1 0 0 0 0      # 关节2（肩部俯仰）
./tool set right all 0 0 0.1 0 0 0      # 关节3（肘部）
./tool set right all 0 0 0 0 0 0.1      # 关节6（手腕）正转
./tool set right all 0 0 0 0 0 -0.1     # 关节6 反转

# 多关节组合（确认安全空间后再做）
./tool set right all 0.1 0.1 0 0 0 0.1
```

**操作纪律**：

1. 首次动某个关节先用 ±0.1 试方向，记下正方向对应的手臂动作
2. 越靠近底座的关节（1、2、3）带动臂体越大，动作前确认空间
3. 不要直接跳到与当前位姿差很远的角度（会快速甩动）
4. 出现异常立即断电/急停，然后 `./tool disable right`

## 6. 验证运动到位（可选）

另开一个 SSH 窗口：

```bash
candump can2
```

观察对应关节帧的位置字段变化。例如关节 6 转 0.1 rad 后，
`0x256` 帧末 4 字节应从 `00 00 00 15`（0.021°）变为约 `00 00 16 6A`（5.73°）。

## 7. 结束流程

```bash
./tool disable right          # ① 失能机械臂
sudo ip link set can2 down    # ② 关闭 CAN 接口（可选）
# ③ 机械臂断电
```

## 8. 故障速查

| 现象 | 排查 |
|---|---|
| `CAN interface doesn't exist.` | `ip -br link` 看 can2 是否在、是否 UP |
| candump 无数据 | 查接线（H/L 反接？共地？）、手臂是否上电、波特率是否 1M |
| 手臂不动 | 是否先 `enable`；`candump` 看 0x2A1 状态帧有无告警位 |
| 手臂乱动 | 立即断电；下次先读当前角度再发相近指令 |
| 状态字告警 | 查 0x261~0x266 帧 data[5]；对照 arm_hardware_interface.cpp 中 STATUS_* 定义 |
